# Tourism Web Application

A tourism web application built using **Node.js**, **Express.js**, **EJS**, **HTML**, **CSS**, and **JavaScript**. The application helps tourists and local residents explore attractions and restaurants in Darjeeling through images, descriptions, ratings, and location details.

## Live Demo

🚀 https://tourism-qqwm.onrender.com/

## Features

- Explore tourist attractions
- Browse restaurants
- View detailed information about places
- Gallery of tourist destinations
- Search places using Fuse.js
- Dynamic server-side rendering with EJS
- JSON-based data storage

## Tech Stack

- **Frontend:** HTML, CSS, JavaScript, EJS
- **Backend:** Node.js, Express.js
- **Data Storage:** JSON
- **Deployment:** Render

## Installation

```bash
git clone https://github.com/S-2102/tourismweb.git
cd tourismweb
npm install
node index.js
```

Visit:

```
http://localhost:3000
```
